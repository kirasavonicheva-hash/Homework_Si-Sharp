## Задание.1 - Ручной счёт

### Задача 1. Система 4x + y = 10; 2x + 5y = 14

1. **Проверка диагонального преобладания:**
   * Первая строка: |4| > |1| (выполнено).
   * Вторая строка: |5| > |2| (выполнено).
   Условие выполняется строго, метод сойдётся с любого начального приближения.

2. **Удобный вид:**
   \[x = \frac{10 - y}{4}\]
   \[y = \frac{14 - 2x}{5}\]

3. **Четыре итерации из старта (0; 0):**
   * **Итерация 1:**
     x₁ = (10 - 0) / 4 = 2,500
     y₁ = (14 - 2 ⋅ 0) / 5 = 2,800
   * **Итерация 2:**
     x₂ = (10 - 2,800) / 4 = 7,200 / 4 = 1,800
     y₂ = (14 - 2 ⋅ 2,500) / 5 = 9,000 / 5 = 1,800
   * **Итерация 3:**
     x₃ = (10 - 1,800) / 4 = 8,200 / 4 = 2,050
     y₃ = (14 - 2 ⋅ 1,800) / 5 = 10,400 / 5 = 2,080
   * **Итерация 4:**
     x₄ = (10 - 2,080) / 4 = 7,920 / 4 = 1,980
     y₄ = (14 - 2 ⋅ 2,050) / 5 = 9,900 / 5 = 1,980

4. **Вывод:** Пара (x; y) спиралевидно (зигзагом) стягивается к точному решению (2; 2), а движение затухающее, потому что на каждом шаге ошибка уменьшается за счёт деления на преобладающие диагональные коэффициенты (4 и 5).

### Задание.3 - Переставленная система x + 3y = 14; 5x + y = 14

1. **Формулы удобного вида:**
   \[x = 14 - 3y\]
   \[y = 14 - 5x\]

2. **Три итерации из старта (0; 0):**
   * **Итерация 1:** x₁ = 14 - 3 ⋅ 0 = 14;  y₁ = 14 - 5 ⋅ 0 = 14
   * **Итерация 2:** x₂ = 14 - 3 ⋅ 14 = -28;  y₂ = 14 - 5 ⋅ 14 = -56
   * **Итерация 3:** x₃ = 14 - 3 ⋅ (-56) = 182;  y₃ = 14 - 5 ⋅ (-28) = 154

3. Из-за смены порядка строк исчезло диагональное преобладание (|1| < |3| и |1| < |5|), поэтому итерации лавинообразно расходятся вместо сходимости.
