## Задание.1

**1. Система $3x + y = 5$; $x + 4y = 9$ (старт $(0; 0)$, $\varepsilon = 10^{-6}$)**
* **Преобладание:** $|3| > |1|$ и $|4| > |1|$ — выполняется.
* **Формулы:** $x = (5 - y) / 3$, $y = (9 - x) / 4$.
* **Итерация 1:** $x = 1{,}667$; $y = 1{,}833$.
* **Итерация 2:** $x = (5 - 1{,}833)/3 = \mathbf{1{,}056}$; $y = (9 - 1{,}056)/4 = \mathbf{1{,}986}$.
* **Итерация 3:** $x = (5 - 1{,}986)/3 = \mathbf{1{,}005}$; $y = (9 - 1{,}005)/4 = \mathbf{1{,}999}$.
* **Отклонение от $(1; 2)$:** сократилось с $(1; 2)$ до $(0{,}005; 0{,}001)$ — примерно в 200–2000 раз.

**2. Рабочая система, 2-я итерация из $(1{,}8;\ 2{,}14;\ 2{,}892)$**
* $x_2 = (18 - 2{,}14 - 2 \cdot 2{,}892)/10 = \mathbf{1{,}008}$ (`1,00760`)
* $y_2 = (25 - 2 \cdot 1{,}0076 - 2{,}892)/10 = \mathbf{2{,}009}$ (`2,00928`)
* $z_2 = (35 - 1{,}0076 - 2 \cdot 2{,}00928)/10 = \mathbf{2{,}997}$ (`2,99738`)

**3. Почему шаг не дороже**

Формулы и количество операций не изменились, а памяти нужно даже меньше, не выделяется отдельный массив под новый вектор. 
В коде изменилась только запись результата: `x[i]` перезаписывается на месте сразу в рабочий массив, а не в буфер `xNew[i]`.

**4. Ловушка порядка строк**
* **Диагональ:** $2, 1, 10$.
* **Преобладание:** в 1-й строке $|2| < |10| + |1|$, во 2-й $|1| < |10| + |2|$ это уже кстати нарушено.
* **Прогноз:** метод разойдётся.
