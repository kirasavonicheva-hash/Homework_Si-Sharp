## Работа программы.
Строит многочлен Лагранжа по таблице точек и считает значения между узлами.

## Задание.1
- **Базис в x=3 (узлы 1,2,4):** ℓ = −0.333333, 1.000000, 0.333333, сумма = 1. P(3) = 5.6667.
- **Совпадение в узлах:** P(xi) − yi = 0 везде (точный ноль).
- **Парабола (2,3,5):** P(2.5)=6.250000, P(3.8)=14.440000, P(4.4)=19.360000 — совпадает с x², разница ~1e−15 (машинный нуль).

## Задание.2
**4-я точка (узел 6 = 9.8):**
| x | 3 узла | 4 узла |
|---|--------|--------|
| 1.5 | 4.0542 | 4.0719 |
| 2.5 | ~4.9 | ~4.9 |
| 3 | 5.6667 | 5.6100 |
| 3.5 | 6.1875 | 6.1344 |
| 5 | 7.7000 | 8.0400 |

В узлах 1,2,4 обе версии дают табличные значения. Между узлами оценки немного сдвигаются. В x=5 для 3 узлов это экстраполяция, для 4 — интерполяция.

**Погрешность sin (3 узла: 0, 0.5, 1):**
| x | 3 узла | 4 узла |
|---|--------|--------|
| 0.1 | 0.00544 | 0.00119 |
| 0.2 | 0.00719 | 0.00151 |
| 0.3 | 0.00622 | 0.00126 |
| 0.4 | 0.00351 | 0.00068 |
| 0.6 | 0.00342 | 0.00058 |
| 0.7 | 0.00589 | 0.00092 |
| 0.8 | 0.00662 | 0.00094 |
| 0.9 | 0.00487 | 0.00062 |

Максимум ошибки: 3 узла = 0.00719, 4 узла = 0.00151.
В x=1.4: 3 узла = 0.061 (экстраполяция), 4 узла = 0.0016.

Четвёртый узел уменьшил ошибку на [0;1] примерно в 5 раз, а участок [1;1.5] из экстраполяции превратил в интерполяцию.

4-я точка слегка сдвинула оценки между узлами (например, P(3): 5.6667 → 5.6100). В x=5 за старой таблицей для 3 узлов была экстраполяция (7.7000), для 4 узлов точка стала внутренней, значение 8.0400.

## Ошибки
- В числителе `(x − xs[i])` вместо `(x − xs[j])`, ломает совпадение в узлах.
- Забыть `j != i`, все базисы обнуляются.
- Думать, что совпадение в узлах = качество интерполяции.
- Считать за пределами таблицы 'прогнозом'.
- Писать `3,5` вместо `3.5`, компилятор прочитает как два числа.
